### PR Description

This update introduces new features, performance improvements, and API refinements:

  ### New features

  - **Mega MoE inference**: added optional fused RMSNorm after combine (BF16/FP32 output).
  - **GEMM**: added `deep_gemm.epilogue.FP8StochasticRounding` and `[1, N]` bias support for BF16 and FP8/FP4 GEMMs.
  - **Experimental kernels (`deep_gemm.experimental`)**: added experimental kernels (no stability guarantees), including fused BF16 GEMM + SwiGLU / (bias) + add + RMSNorm,
    `batched_bf16_newton_schulz`, `fp8_gemm_nt_segmented_k256`, and fused decoding kernels (`v41f_qkv_lora`, `v41f_wv_o_proj`).

  ### Performance improvements

  - **Mega MoE inference**: low-latency optimizations, batched dispatch pulling, reduced atomic traffic, and streaming stores for combine reduce.
  - **GEMM heuristics**: tuned L2 swizzle heuristics and TMA store stage selection for deeper input pipelines.
  - **Mega mHC**: host-resolved norm partitioning and faster BF16 conversion / `exp` computation.

  ### Fixes

  - Fixed missing async global proxy fences and tail task draining in Mega MoE inference.
  - Removed `%gridid` dependency in Mega mHC split barriers for safe CUDA graph replay.

  ### API changes

  - Mega MoE inference APIs are renamed to `*_inference`; legacy names remain available via `deep_gemm.mega_moe.compat`.
  - `mega_mhc` now supports Shifted mode only (Normal mode removed).
