### Floating composer in maximized panels, Auto mode edits, and voice context

This release adds a floating composer with live status inside maximized side panels, expands Auto mode to approve safe file edits outside your current project, and carries spoken context from ended voice calls into local conversations. It includes 13 improvements and 26 fixes.

**Improvements:**

*   Added a floating composer pill at the bottom of maximized side panels with a live status bar showing agent progress, unread replies, and saved drafts; expand it to send follow-ups or start dictation without leaving the maximized view.
*   Expanded Auto mode to automatically approve safe file edits in other version-controlled repositories and non-replacing file additions outside your current project without prompting for confirmation.
*   Carried spoken context from live voice calls that end before handoff into the local conversation so the agent remembers what you discussed.
*   Added discovery for custom skills stored in `~/.agents/skills`, with skills in `~/.gemini` taking precedence if two skills share the same name.
*   Kept disabled plugin and Marketplace controls visible in Customizations as grayed-out options with an explanation tooltip when an organization administrator turns them off, while built-in plugins continue to work.
*   Enabled authorizing cloud automations for remote agents directly from the desktop app using a Google sign-in prompt that opens in your system browser.
*   Organized app logo menu actions on Windows and Linux into dedicated File and Zoom submenus.
*   Updated the Installed tab in Customizations to display up to 16 plugins initially and reveal all remaining installed plugins at once when you select See more.
*   Rendered LaTeX mathematical equations in subagent replies inside the main conversation thread instead of displaying raw TeX markup.
*   Requested offline access during OAuth sign-in for MCP servers that support it, allowing refresh tokens to be issued automatically and reducing repeated sign-in prompts.
*   Added a dashed circle icon alongside strikethrough text for skipped steps in task checklists so they stand out clearly from pending steps.
*   Displayed a standalone info icon with a hover tooltip for models with descriptions in the model selector even when they do not have a status badge.
*   Reduced disk reads and memory usage when updating conversation summaries during active turns.

**Fixes:**

*   Fixed an issue where typing `localhost` or a local port into the built-in browser address bar defaulted to HTTPS and failed to load local HTTP development servers.
*   Fixed an issue where the default Open Keyboard Shortcuts binding did not work on macOS by changing it to `Option+Cmd+/` and removing the unreachable `?` shortcut.
*   Fixed an issue where selecting the same model for both Orchestrator planner and executor fell back to a different default model instead of running as a single agent on the chosen model.
*   Fixed an issue where selecting System default as your microphone could open a previously used physical microphone instead of following your operating system's default input device.
*   Fixed an issue where LaTeX equations containing `\label` commands failed to render and displayed an error banner.
*   Fixed an issue where unformatted shell variables in chat messages were mistakenly rendered as LaTeX math.
*   Fixed an issue where copying text from raw markdown and code viewers collapsed blank lines.
*   Fixed an issue where an empty organization prepaid wallet was misreported as a temporary model quota limit with retry prompts instead of showing a clear notice.
*   Fixed an issue where attaching a truncated or corrupt image could cause subsequent turns in the conversation to fail repeatedly.
*   Fixed an issue where long-running turns could fail with an authentication error when an OAuth token expired mid-session by preserving early token refresh and retrying once on expired credentials.
*   Fixed an issue where, on Windows, installed plugins were not found when the active project lived on a different drive than your `.gemini` directory.
*   Fixed an issue where failed plugin or skill actions showed error messages across other Customizations pages without a dismiss button and rendered in plain gray text.
*   Fixed an issue where hovering over a running conversation in the sidebar showed a Stop button instead of the Archive action, and restored hover Archive on sidebar conversations outside Inbox Mode.
*   Fixed an issue where an unsent message draft deleted in one tab or window could reappear when switching or closing another open tab.
*   Fixed an issue where sending an immediate follow-up or using Send Now behind an in-flight message could fail to cancel the active generation.
*   Fixed an issue where closing a maximized side panel or resizing the window could leave the conversation area blank.
*   Fixed an issue where Enterprise accounts saw an empty agent selector and could not open the in-app Give Feedback screen from the command palette.
*   Fixed an issue where allowing non-project file access under legacy permissions could bypass protections on sensitive configuration files.
*   Fixed an issue where typing quickly in the Add MCP Server search box could display stale results from an earlier query or clear the loading spinner early.
*   Fixed an issue where interrupted remote agent turns did not display an error card with a retry button.
*   Fixed an issue where Markdown tables repeatedly re-measured their columns during sidebar resize animations.
*   Fixed an issue where the collapsed Update Available icon in narrow windows had no tooltip on hover or keyboard focus.
*   Fixed an issue where the empty middle area of the New Conversation title bar could not be dragged to move the window.
*   Fixed an issue where opening a deep link to a specific setting failed to scroll to and highlight that row.
*   Fixed an issue where switching between conversations caused the conversation navigator rail to briefly flash.
*   Fixed an issue where dismissed onboarding suggestions containing commas could reappear after reloading the app.
